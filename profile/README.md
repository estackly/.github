## Build on any Estackly store

[Estackly](https://estackly.com) is an online store builder. This is where we keep the open-source tools for building on top of it.

The **Storefront API** gives your app, custom storefront or integration a store's real products, prices, carts, customers and orders. Checkout stays on the store, so payments, tax and shipping never pass through your code.

### Start here

| Repo | What it's for |
| --- | --- |
| [nextjs-storefront](https://github.com/estackly/nextjs-storefront) | A headless storefront in Next.js. Click **Use this template** to start your own. |
| [storefront-js](https://github.com/estackly/storefront-js) | The JavaScript and TypeScript SDK for the Storefront API. |
| [storefront-api](https://github.com/estackly/storefront-api) | The OpenAPI 3.1 spec, if you'd rather generate a client in another language. |
